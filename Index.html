Alat dan Bahan

Kabel UTP

Kabel Unshielded Twisted Pair (Cat5e/Cat6) sebagai media transmisi data.

Konektor RJ45

Konektor yang dipasang pada kedua ujung kabel UTP.

Tang Crimping

Alat untuk mengupas, memotong, dan mengunci konektor RJ45 ke kabel UTP.

LAN Tester

Alat untuk menguji keberhasilan dan keterhubungan pin kabel LAN.

Langkah Merangkai Kabel LAN (Crimping)

  1. Kupas Jaket Kabel UTP: Kupas pelindung luar kabel UTP sepanjang sekitar 2 cm menggunakan pemotong pada tang crimping.
  2. Urai & Luruskan Pillinan Kabel: Buka pilinan 8 warna kabel kecil di dalamnya, lalu luruskan.
  3. Urutkan Warna Sesuai Standar:

    Untuk menghubungkan 2 Laptop langsung (Peer-to-Peer), disarankan menggunakan standar Crossover (atau Straight jika laptop mendukung Auto-MDIX).

    Pin Ujung A (T568A) Ujung B (T568B - Crossover)
    1Putih HijauPutih Orange
    2HijauOrange
    3Putih OrangePutih Hijau
    4BiruBiru
    5Putih BiruPutih Biru
    6OrangeHijau
    7Putih CokelatPutih Cokelat
    8CokelatCokelat
  4. Ratakan Potongan: Potong rata susunan kabel hingga tersisa sekitar 1.5 cm.
  5. Masukkan ke RJ45: Masukkan susunan kabel ke dalam konektor RJ45 sampai ujung tembaga menyentuh bagian paling depan konektor.
  6. Press dengan Tang Crimping: Masukkan konektor ke lubang tang crimping dan tekan dengan kuat hingga terdengar bunyi "klik".
  7. Pengujian dengan LAN Tester: Masukkan kedua ujung RJ45 ke LAN Tester. Jika lampu indikator 1-8 menyala bergantian sesuai urutan standar, maka kabel siap digunakan.

Menghubungkan 2 Laptop & Sharing File

A. Konfigurasi IP Address (Static)

  1. Hubungkan kabel LAN ke port RJ45 pada Laptop A dan Laptop B.
  2. Buka Control Panel > Network and Sharing Center > Change adapter settings.
  3. Klik kanan pada Ethernet, pilih Properties.
  4. Pilih Internet Protocol Version 4 (TCP/IPv4), klik Properties.
  5. Atur IP Address secara manual:
    • Laptop A: IP = 192.168.1.1 | Subnet Mask = 255.255.255.0
    • Laptop B: IP = 192.168.1.2 | Subnet Mask = 255.255.255.0
  6. Buka Command Prompt (CMD) dan ketik ping 192.168.1.2 dari Laptop A untuk memastikan koneksi berhasil (Reply from...).

B. Langkah Sharing File / Folder

  1. Klik kanan folder yang ingin dibagikan, pilih Properties.
  2. Masuk ke tab Sharing, lalu klik tombol Share....
  3. Pilih Everyone dari menu dropdown, klik Add, lalu atur Permission Level (Read/Write). Klik Share.
  4. Pada laptop tujuan, buka File Explorer dan ketik di address bar: \\192.168.1.1 (IP Laptop sumber).
  5. Folder yang dibagikan kini dapat diakses dan diunduh.
